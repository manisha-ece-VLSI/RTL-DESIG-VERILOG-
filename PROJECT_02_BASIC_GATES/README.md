# PROJECT 02 - Basic Gates & Adders
Implementation of fundamental digital building blocks.

## Modules
- `all_gates` - All basic logic gates (AND, OR, NOT, NAND, NOR, XOR, XNOR)
- `half_adder` - Half Adder
- `full_adder` - Full Adder behavioral
- `full_adder_using_half_adder` - Structural using 2 Half Adders

## Concepts
Gate-level, Behavioral, Structural modeling
